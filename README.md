# DeepSeek Quant Lab

**在线体验：[打开 DeepSeek Quant Lab](https://deepseek-quant-lab-xu.streamlit.app/)** · [云端密钥配置](DEPLOY.md)

本地运行的中文 A 股量化研究工作台。当前交付**第一阶段 MVP**：历史行情 → AI 研究 → 人工采用参数 → Python 回测 → 分段验证 → 保存实验 → AI 复盘。无真实资金交易能力。

## 免费云端部署

使用 GitHub 保存源码、Streamlit Community Cloud 运行 Python。见 [DEPLOY.md](DEPLOY.md)。公网访客的数据按会话隔离；只有站主登录后才能使用服务端 DeepSeek Key。大陆直连可用性不作保证。

## 立即启动（Mac）

首次下载请先按下方命令创建虚拟环境。已安装后，Finder 双击 `start.command`，或在 PyCharm Terminal 执行：

```bash
cd deepseek-quant-lab
.venv/bin/python -m streamlit run app.py --server.address=127.0.0.1
```

浏览器打开 <http://127.0.0.1:8501>。停止时在对应终端按 `Control+C`。只监听本机地址，不需要云服务器。

PyCharm：Open 打开本项目目录，Python Interpreter 选择本目录下 `.venv/bin/python`。无需在系统 Python 全局安装。

迁移到另一台 Mac：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
chmod 600 .env
.venv/bin/python -m streamlit run app.py --server.address=127.0.0.1
```

实际验证环境：macOS / Apple Silicon arm64 / Python 3.14.7。`requirements.txt` 固定直接依赖，`requirements.lock.txt` 是本次运行的完整解析结果；未经验证的其他 Python 版本不保证安装成功。Python 3.14 的部分二进制包要求较新的 macOS。

## 填写 DeepSeek Key

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建自己的 API Key，确认 API 账户余额。
2. 在 PyCharm 项目文件树打开根目录 `.env`（隐藏文件），填写 `DEEPSEEK_API_KEY=你的密钥`。不要在聊天里发送 Key。
3. 模型默认 `DEEPSEEK_MODEL=deepseek-flash`；2026-10-22 查询官方模型文档支持该名称。可以修改模型环境变量；在系统设置测试模型列表。
4. 页面进入「系统设置」→「测试官方连接 / 获取模型列表」。这只验证鉴权和模型可用性。
5. 进入「AI 策略研究」发送问题，才能验证一次真正的生成调用；会产生 API 费用。

本次环境**没有 Key**，仅验证官方接口无鉴权访问返回 HTTP 401。不能声称真实 AI 生成已经通过。客户端已真实实现 HTTP 请求，测试中 MockTransport 只用于自动化契约和故障测试；应用不会用假 AI 回复代替接口。

使用官方 HTTPS 地址；不支持通过页面改成第三方中转。`.env` 不进入 Git/源码交付包；Key 不写入数据库、提示词或日志。识别到的 Key 字符串会在对话发送前脱敏，但不要主动输入账号、密码等敏感资料。

可选设置 `DEEPSEEK_INPUT_PRICE` / `DEEPSEEK_OUTPUT_PRICE`（美元/百万 token）用于估算成本；不填写就记录 token、费用未知。缓存与峰谷费率以官方账单为准。不会把未配置的费用显示为零。

## 第一次使用

1. **股票行情**：输入 `000001` 或其他普通主板代码，选择腾讯或东方财富，选日期后获取。内置中文名称目录只有五个示例，完整名称搜索留待证券主表接入。
2. 查看 K 线、成交量（股）、MA5/10/20/60、MACD、RSI14。所有数字附带行情类型、最后交易日与下载时间。可以保存自选。
3. **策略回测**：选 A 双均线（例如5/20）或 B 成交量突破（例如N=20、1.5倍量、退出均线10），初始资金默认10000元。
4. 对真实数据，先核实股票在整个区间是普通成熟主板证券，并核实无除权除息，再确认研究假设。参数改变仅用于回测，不会发出订单。
5. 点击「运行回测与分段验证」。查看收益、年化、最大回撤、胜率、盈亏比、夏普、费用、资金曲线、同仓位买入持有、逐笔成交和未成交原因。
6. 命名实验并保存；在 **策略实验室** 比较历史版本并导出 JSON。
7. **AI 策略研究**：选一个已保存实验，查看即将发送的行情摘要及结果，再发送复盘问题。AI JSON 经 Pydantic 校验后才能保存。点击人工采用参数后去回测页运行。

没有网络或没有 API Key：可载入清楚标注的「人工合成离线示例」，运行两种策略、分段验证、保存和比较。其价格和收益全部是测试用途，不能解释为真实股票表现。断网时也可载入之前成功下载的历史缓存。

## 回测规则与重要边界

- 仅接受沪深普通主板代码。暂不支持科创板、创业板、ETF、B股、北交所、ST、新股、退市整理。**代码前缀不能证明历史非ST状态**，必须核实历史证券状态；本版未接入 point-in-time 证券主表。
- 收盘生成候选状态，最早下一根日线开盘尝试成交。未成交时若信号仍成立，下一日重新尝试；信号逆转则取消原意向。只做多、全额单股建仓/清仓，无融资、无做空。
- 历史起止范围从2015-08-03开始。佣金默认万分之1.5、每笔最低5元；卖出印花税在2023-08-28由0.1%降至0.05%。过户费在2022-04-29由0.002%降至0.001%；按中信公开费表，默认深市由券商承担，沪市计入客户成本。历史深市向客户收费方式与个人合同可能不同，可在设置中改为另收；以本人交割单校准。佣金默认已包含经手费和证管费，未重复计收。
- 100股整数买入，计入费用后资金不足一手则拒绝；卖出全部当前持仓。买入资金比例默认95%。单股单仓位日频设计保证买入当日不卖出；还检查买入日期。
- 开盘涨停拒绝买入、开盘跌停拒绝卖出，零成交量/停牌标记拒绝。常规上下限按前收盘价±10%、价格精度0.01估算；无官方逐日涨跌停参考价，除权日、特别状态不可当成普通日。
- 默认滑点单边5基点。若滑点价超出日内高低价，整笔拒绝。成交量容量用**上一交易日**成交股数的1%，超过容量的卖单整笔拒绝；这是一种保守研究约束，不是开盘集合竞价可成交量预测。日线无法精确模拟订单队列、部分成交、盘口与盘中临停。
- 策略指标只使用当时及过去数据；突破基准排除当天。验证区间可使用之前数据预热，但各分段独立现金起步，不跨分段带仓。
- 使用不复权原始价格成交，避免未来前复权因子进入成交价格。**未实现现金分红、红利税、配股、送转股及完整公司行动对账**；显式标记公司行动的输入将拒绝回测，公共数据未标记的事件仍可能漏检。不复权价格收益不是完整总回报，跨除权区间不能据此判断策略盈利能力。
- 单股票是用户主动选择的，存在选择偏差与幸存者偏差。没有历史全市场含退市证券的 point-in-time 数据，不能声称已经消除幸存者偏差。
- 末日持仓按收盘价计值，不强制按末日收盘卖出；未预扣未来卖出成本。胜率、盈亏比只计已平仓往返，无法定义时显示空值。夏普以252交易日、无风险利率0计算；年化以实际自然日计，短样本年化不稳定。
- 样本外只是时间隔离；一旦反复看其结果调参，就不再是未见样本。滚动验证、参数搜索预算与最终封存测试属于第三阶段。

## 行情与API故障行为

- 全部外部行情均标记历史日线；不把免费下载接口标为真实实时。没有实时授权或交易所时间戳质量保证。下载日的日线在北京时间16:00前被排除，避免未完成 K 线进入回测。
- 每次行情请求放在可终止进程内，35秒超时，最多两次。失败明确提示，不自动回退成测试数据、不篡改系统代理、不关闭TLS验证。
- 腾讯成交量/金额会和OHLC作单位一致性核验，处理已安装AKShare版本的 `sz000*` 手/股歧义；无法验证时拒绝数据。
- 市场状态仅按Asia/Shanghai常规时段显示，节假日和临时休市未核验，不能授权交易。历史、过期、异常、合成数据全部不能进入模拟订单路径。
- API 429/服务端错误有限重试，最多3次；鉴权和余额错误不重试。网络超时结果可能已经计费，故不自动重发。JSON不合法、截断或参数超出白名单时拒绝采用。
- AI 不能生成执行代码，不能执行自然语言订单。只有内置两种确定性模板的数值参数可被人工采用。文字提议的其他条件不自动执行。
